# Method examples

Start with the [Python Method notebook](../../docs/tutorials/methods/write_your_method.en.ipynb)
([한국어](../../docs/tutorials/methods/write_your_method.ko.ipynb)).
It writes and runs ranking and OLS functions on prepared data.

- [authoring/](authoring/README.md): functions and offline data used by that notebook.
- [project/](project/README.md): the complete Method and Skill project for CLI and server use.

Follow the [Method guide](../../docs/guides/methods.md), then
[use the project](../../docs/guides/method-projects.md) in the admin UI and through AI.
Automated checks are in `tests/examples/`; internal SDK and numerical cases are in `tests/support/methods/`.
