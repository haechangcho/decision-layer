# Statistical examples

These optional examples use native statistical libraries and explicitly selected
semantic inputs. `binary_regression.py` contains the reusable calculation;
`dowhy_basics.py` and `continuous_regression.py` demonstrate execution.
`teaching_data.py` supplies synthetic observations for the advanced notebook.

```bash
.venv/bin/python -m examples.methods.statistics.dowhy_basics
.venv/bin/python -m examples.methods.statistics.continuous_regression
```

Use the dependencies in `constraints-py311.txt` when reproducing the full statistical
test environment. See [statistical Methods](../../../docs/guides/statistical-methods.md)
for assumptions and limitations.
