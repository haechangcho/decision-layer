# Codex Complete Journey pilot — 2026-10-27

**Superseded for product comparison:** the campaign baseline was given a
campaign-specific prebuilt OLS tool. The user rejected that baseline. Preserve
these diagnostic results for history only; do not use them as evidence of
Decision Layer's value or as the main comparison.

Diagnostic only: one run per task and condition. This is not an estimate of
general accuracy, a causal effect of the product, or a price measurement. The
Codex CLI default model was used with user configuration ignored; the exact
model was not pinned or independently verified. Runs were sequential, with
automatic approval review. Input token counts include cached input tokens.

The sales task asked for July–August 2001 receipts and units, ranked departments
by absolute signed receipts change, and inspected the selected department's
brands and units. Both answers gave 375,934.24 → 411,644.74 in receipts,
14,038,723 → 13,828,603 units and GROCERY +22,183.29; independent SQL
confirmed these totals and the GROCERY units 100,402 → 112,443. Both answers
reported that the total receipts and units moved in opposite directions without
claiming a price or causal effect. Decision Layer recorded both required
single-page retrieval checks; this does not establish source completeness or
cross-query snapshot consistency. The Recipe queries all department-by-brand
groups for both periods; the baseline used a distinct query sequence.

The campaign task compared campaign 8 target-list members with nonmembers,
using subsequent 30-day household sales as outcome and prior sales and purchase
frequency as covariates. Both used the same starter OLS calculation and reported
the target-membership coefficient +32.4658 for 2,008 observations as an
association, not a causal effect. Independent SQL cross-products and a linear
solve gave +32.46579465777095; the groups had 1,043 and 965 observations.
The baseline's dedicated tool also exposed raw group summaries, whereas the
Recipe's output exposed the regression result. The two bundles therefore differ
in information and query surfaces; this does not isolate the effect of Recipes.

Local trial traces and diagnostics remain under `/private/tmp/dl-sales-pilot-v2-default`
and `/private/tmp/dl-campaign-pilot-v2` and have not been reviewed for publication.
CLI model calls were made using the signed-in ChatGPT account; no dollar cost
was provided. A preceding attempt specifying `gpt-6` failed before any analysis
because that model ID was unsupported by the CLI account. These failed attempts
are not included in the table. The pilot is not the randomized repeated benchmark.
