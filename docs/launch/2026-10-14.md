# Launch package — draft, not published

## Audience and promise

For analysts using an AI client against governed semantic data who repeat the same
investigation: teach your AI how your team analyzes data. Save a reviewed procedure
and apply it to a new period with its steps, checks and evidence recorded.

“Teach” means an executable Recipe, not model training. This release demonstrates
descriptive group selection, not causal explanation or autonomous analysis approval.

## Release notes

- A 360-row synthetic Cube sample with no company credentials.
- An installer that prepares the sample, verifies replay, and registers Claude Code's
  MCP connection without a local Python installation or manual MCP JSON.
- Same-Recipe reexecution: January Home, February Grocery, March tied leaders requiring input.
- Real UI recording, English/Korean quickstart and user-first README.
- Separate default-catalog and explicitly enabled optional evaluation scenarios.
- Scoped first contribution tasks and a reproducible live-model comparison runner.

Prerequisites remain Node.js, Claude Code and running Docker with Compose v2.
The checkout path also needs Git. First builds download packages and images.
macOS was exercised; Linux/WSL2 behavior is not independently validated yet.
