# Create a Recipe

A Recipe saves a recurring analysis as a procedure. For example: **find the highest-revenue product, then inspect its revenue by region**.

## Create a new Recipe

1. Select a metric under **Metrics** and choose **Create Recipe**.
2. Add steps and select each step's Method and inputs.
3. Choose **Check result** and review the results.
4. Save a draft, then publish it.

## Save an existing analysis

Choose **Register as Recipe** on a completed [Run](runs.md).
To change the procedure first, choose **Edit before saving**.

## Save how to choose a target

Product A may lead revenue in January and product B in February.

- **Analyze product A**: select A again.
- **Find and analyze the highest-revenue product**: select a target at each execution.

Ties or insufficient results ask for user input.

Run a saved Recipe with different dates and inputs. Each execution's results and queries are recorded in a [Run](runs.md).
