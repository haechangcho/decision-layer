# Runs and evidence

A Run records one analysis, from its question to the inputs, queries and results.

## Read a result

Select an analysis under **Runs**.

1. Read the question and conclusion.
2. Select a step to inspect tables and charts.
3. Open **Applied settings**, **Queries** and **Sources** to review the evidence.

![Run review with example data](../assets/run-review.png)

A completed calculation can still fail validation. Read warnings and checks alongside the results.

## When analysis stops

- **Needs input**: select missing dates or variables.
- **Refused**: read the reason and correct inputs or data conditions.
- **Missing definition**: have the model owner update Cube, then start a new analysis.

## Reuse or delete

Choose **Register as Recipe** on a completed Run to reuse the procedure.

Owners can delete Runs after execution finishes. Results and queries are removed; an already registered Recipe is kept.
