# Decision Layer

**Let people and AI reuse your team's reviewed analysis methods.**

Query data from a semantic layer, execute registered analyses and record inputs, queries and results.

- **Method**: a calculation function or analysis instructions for AI
- **Recipe**: a procedure composed of Methods
- **Run**: a record of one analysis

The semantic layer owns metric definitions and joins. Decision Layer manages analysis methods and procedures.
