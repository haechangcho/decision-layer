# 인터페이스 디자인

웹과 문서는 `web/styles/tokens.css`를 함께 사용합니다. Heartcount의 코랄색 주요 동작, 중립 표면, 코발트색 데이터 표시를 기준으로 합니다.

- 코랄색은 주요 동작과 선택한 그래프 노드에 사용합니다. 작은 글자와 흰색 글자가 들어가는 버튼에는 명도 대비가 높은 `--dl-action`을 사용합니다.
- 페이지 배경과 탐색 메뉴는 중립색으로 유지합니다. 초록색은 검증 성공을 표시할 때만 사용합니다.
- 데이터 표시는 코발트색을 사용합니다. Method가 검증하지 않은 유의성이나 인과성을 차트 색으로 암시하면 안 됩니다.
- 여백과 글자 위계로 정보를 묶습니다. 테두리는 입력 컨트롤, 표, 분석 그래프·쿼리 뷰어 같은 도구에 사용합니다.
- 그래프 노드 크기는 일정하게 유지합니다. 노드는 훑어볼 수 있는 요약이고, 단계의 전체 목적과 근거는 선택한 단계 상세에서 제공합니다.
- 질문과 기록된 답변을 먼저 보여줍니다. Recipe 등록은 쉽게 찾을 수 있게 하고, 결과·설정·쿼리·출처를 같은 수준의 탭으로 제공합니다.

실제 Run으로 데스크톱과 좁은 모바일 화면을 확인하세요. 그래프 선택, 키보드 탭 이동, Recipe 등록, 쿼리 복사를 검증합니다. 페이지마다 별도 강조색을 추가하지 않습니다.
