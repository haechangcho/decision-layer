# Method 이해하기

Method는 데이터에 적용할 분석 방법입니다. 데이터 과학자가 함수를 등록하면 사용자와 AI가 필요한 지표를 연결해 같은 분석을 재사용합니다.

Python Method는 계산 함수를 실행하고, Skill Method는 AI가 따를 분석 지침을 담습니다. 아래에서는 Python 함수를 연결하는 흐름을 설명합니다.

## 함수와 데이터는 따로 정합니다

등록할 때는 **어떻게 계산할지**, 실행할 때는 **어떤 데이터를 사용할지** 정합니다.

| 시점 | 정하는 것 | 예시 |
|---|---|---|
| Method 등록 | 계산 함수와 입력 조건 | 숫자형 결과 변수와 설명변수가 필요한 OLS |
| 분석 실행 | 실제 지표, 변수, 기간 | 고객별 구매 금액, 광고 노출 횟수, 2월 데이터 |

매출이나 고객의 정의와 집계 방식은 semantic layer에 둡니다. Method는 그 정의를 사용해 가져온 데이터를 계산합니다.

## AI가 분석을 요청하면

1. AI가 등록된 Method와 입력 조건을 확인합니다.
2. Semantic catalog에서 지표와 차원을 선택합니다. 의미나 기간이 모호하면 사용자에게 묻습니다.
3. Decision Layer가 입력을 검사하고, 데이터를 조회해 함수에 전달합니다.
4. 서버는 입력, 쿼리와 결과를 Run에 기록하고, AI는 결과를 읽고 설명합니다.

Web, REST와 MCP도 같은 실행 코드를 사용합니다. 노트북의 로컬 세션은 이 흐름 중 조회와 함수 실행을 확인하는 개발용 환경입니다.
