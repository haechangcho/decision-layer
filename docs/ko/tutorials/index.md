# 직접 해보기

**Python Method 만들기**부터 시작하세요. 함수 작성, 등록, 입력 선택, 결과 확인을
순서대로 해봅니다. 준비된 데이터로 실행하므로 Cube 서버나 AI 연결은 필요 없습니다.

| 노트북 | 내용 |
| --- | --- |
| [Python Method 만들기](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/write_your_method.ko.ipynb) | 순위 함수와 OLS를 등록하고 실행 |
| [고급 Method 작성](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/advanced_method.ko.ipynb) | 타입 기반 SDK, 여러 입력, 통계 함수 연결 |
| [조회 시나리오](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/query_scenarios.ipynb) | 다양한 조회와 정답 검증 |
| [첫 SDK Method](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/first_method.ipynb) | 클래스 기반 SDK와 실제 Cube 연결 |
| [비교 분석](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/peer_comparison.ipynb) | 세 번의 조회를 하나의 분석으로 조합 |
| [PyWhy 검토](https://github.com/haechangcho/decision-layer/blob/main/docs/tutorials/methods/pywhy_review.ipynb) | 선택적 추정 방법 실험 |

저장소를 내려받아 Jupyter나 VS Code에서 엽니다. 입문 노트북은 이 저장소와
`stats` 의존성이 설치된 Python 커널을 사용합니다. 예제의 Python 코드는
`examples/`, 자동 실행 검증은 `tests/examples/`에 있습니다.

만든 함수를 관리자 화면과 AI에서도 사용하려면
[서비스 사용 가이드](../guides/method-deployment.md)로 이어가세요.
제품 개발에 참여한다면 [저장소 구조](../guides/repository.md)를 참고하세요.
