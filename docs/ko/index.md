# Decision Layer

**팀이 검토한 분석 방법을 사람과 AI가 함께 사용합니다.**

Semantic layer에서 데이터를 가져와 등록된 분석을 실행하고, 입력과 쿼리, 결과를 기록합니다.

- **Method**: 계산 함수 또는 AI가 따를 분석 지침
- **Recipe**: 여러 Method를 조합한 분석 절차
- **Run**: 한 번의 분석 기록

지표 정의와 조인은 semantic layer에서, 분석 방법과 절차는 Decision Layer에서 관리합니다.
