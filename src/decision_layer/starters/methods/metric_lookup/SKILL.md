# 지표 조회

선택한 지표를 조회하고, 질문에 필요한 값을 설명합니다.

1. 질문에 필요한 항목별로 지표를 조회합니다. 전체 값이 필요하면 합계도 별도로 조회합니다.
2. 지표의 단위와 조회 기간을 함께 설명합니다. 합계, 평균, 비율은 지표에 정의된 의미대로 읽습니다.
3. 데이터가 없거나 일부만 조회되었다면 그 범위를 밝힙니다.
4. 조회한 값으로 답할 수 있는 내용만 정리합니다. 원인이나 통계적 차이를 확인하려면 해당 분석 Method를 사용합니다.
