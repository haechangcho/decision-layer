# 항목별로 나누어 살펴보기

지표를 상품, 지역 등으로 나누어 보고, 이어서 살펴볼 항목을 선택합니다.

1. 질문에 맞는 기준으로 지표를 나누어 조회합니다. 예를 들어 매출을 상품 부문별로 봅니다.
2. 값의 크기와 분포를 살펴봅니다. 비교 기간이 주어졌다면 같은 기준으로 조회해 함께 보여줍니다.
3. 다음에 살펴볼 항목을 선택하고 이유를 설명합니다. 한 항목을 골라야 하는데 공동 1위라면 사용자에게 확인합니다. 미리 정한 선택 규칙이 있으면 따릅니다.
4. 선택한 항목과 범위를 다음 분석에 전달합니다. 지역별 분석으로 이어간다면 선택한 상품 부문의 데이터만 살펴봅니다.

값이 큰 항목을 원인이나 이상 현상으로 단정하지 않습니다. 변화율이나 통계 검정이 필요하면 등록된 계산 Method를 사용합니다.
