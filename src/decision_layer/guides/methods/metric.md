# 지표 조회 참고 지침
analysis.metric_lookup의 현재 명세를 확인한다. 지표·단위·기간·대상을 발견하고 하나의 Run에서 실제 쿼리를 기록한다. 이 참고 지침을 읽은 것만으로 계산 단계나 검사 통과가 생기지 않는다. 실행 단계에는 query_execution Skill을 사용하고, 데이터 완전성이나 공식 의미를 자동 보증하지 않는다.
