# 동료 집단 비교 참고 지침
analysis.peer_comparison의 명세를 읽고 대상·기간·지표·집단 조건을 확인한다. 대상과 나머지 집단을 같은 기간·범위에서 조회하고 대상 제외 조건을 기록한다. 표본 수·노출·정의·검사 상태를 확인한다. 지침을 읽었다고 비교군 적절성·위험 조정·인과성을 검증한 것으로 표시하지 않는다. 실제 실행 단계에는 query_execution Skill을 사용한다.
